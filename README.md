# Reconocimiento_De_Patrones_Grupo01
## Group_Project
La epilepsia afecta a millones de personas en el mundo. El monitoreo continuo de EEG genera horas de señal que un neurólogo debe revisar manualmente para detectar crisis. Un sistema de detección automática podría reducir significativamente el tiempo de análisis y facilitar alertas en entornos clínicos.
